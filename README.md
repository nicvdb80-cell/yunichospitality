# Yunic Hospitality

**Where Indonesian Soul Meets the World**

The flagship website for the Yunic brand — connecting events, private dining, consulting, chef collaborations, and pop-up experiences rooted in the Indonesian Archipelago.

## Brand Family
- [Yunic Dining](https://yunicdining.com) — Private dining experiences
- [Yunic Shop](https://yunicshop.com) — Indonesian pantry & products
- Yunic Hospitality — This site, the parent brand

## Tech Stack
- Plain HTML / CSS / JS — no build tools
- Deployed via Vercel (auto-deploy from `main`)

## Development
Push changes to `main` and Vercel auto-deploys.
